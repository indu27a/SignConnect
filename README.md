\# SignConnect – AI-Based Sign Language Translator



SignConnect is an AI-powered Sign Language Translator designed to recognize hand gestures and convert them into text using machine learning.



\## Project Overview



The project combines computer vision, machine learning, and web technologies to make communication more accessible.



\## Technologies Used



\### Frontend



\* React.js

\* JavaScript

\* HTML

\* CSS

\* MediaPipe Tasks Vision



\### Backend



\* Python

\* Django

\* Django REST Framework



\### Machine Learning



\* Random Forest Classifier

\* Scikit-learn

\* NumPy

\* MediaPipe



\## Key Features



\* Real-time hand detection using webcam.

\* Hand landmark extraction using MediaPipe.

\* AI-based sign prediction.

\* Conversion of recognized gestures into text.

\* Text-to-speech functionality.

\* Interactive React frontend.

\* Django REST API integration.



\## Supported Signs



The current trained machine learning model supports:



\* A

\* B

\* C

\## Installation



Clone the repository:



```bash

git clone https://github.com/indu27a/SignConnect.git

```



Install backend dependencies using the provided requirements file.



Frontend dependencies can be installed using npm inside the frontend project directory.
